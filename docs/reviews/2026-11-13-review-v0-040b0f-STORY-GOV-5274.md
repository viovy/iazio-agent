## 1. Executive Summary & Forensic Context

During multi-slot host executions on `debian` hosting co-located repository trees (`/home/romeo/work/meta-repo` and `/home/romeo/work/meta-repo-02`), an active autonomous job (`job_5caae91005a69cef`) executing `STORY-GOV-5272` was simultaneously attributed to both worktree slots (`Lock: RUNNING_HARNESS`, `Active Job: job_5caae91005a69cef`), while `/home/romeo/work/meta-repo-02` remained locked in `Queue: PAUSED` displaying the error banner `Worktree Uncommitted Changes / Job scheduling is halted`.

This review verified the comprehensive, cross-submodule resolution on disk:
1. **`iazio-harness-api` (`79bbfd9`)**: Prevents false binding to idle sibling slots sharing a slot family, eliminates raw prefix substring matching via exact path boundary normalization, ensures atomic eviction of sibling repo locks when binding a specific worktree, re-anchors both `job.Repo` and `job.WorktreePath` on runtime reports, and blocks cross-slot HTTP view enrichment.
2. **`iazio-agent` (`3e4eded`)**: Replaces substring process line inspection with descending-length path-boundary matching (`matchCommandLineRepoPath`, `commandLineContainsRepoPath`, boundary checks), preventing prefix collisions between `/work/meta-repo` and `/work/meta-repo-02`. Unifies `AckLease` invocations to propagate `worktreeDir` through `AckLeaseWithWorktree`.
3. **`iazio-web` (`b048f2a`)**: Suppresses misleading halted-scheduling error cards when `repo.lock == RUNNING_HARNESS` or an active job is executing, retaining live modified files counts.
4. **`iazio-infra` (`c596480`)**: Documents the multi-slot attribution and lease ack mechanics in `wiki/Iazio-Harness-API.md`, `wiki/Iazio-Agent.md`, and `wiki/Iazio-Web.md`, with zero wiki drift.

## 2. Deep Architectural & Functionality Analysis

### 2.1 Substring Collision Elimination & Path Boundary Semantics (`iazio-agent`)
In [internal/supervisor/execution_detector.go](file:///Users/romeo/work/meta-repo-02/iazio-agent/internal/supervisor/execution_detector.go#L268-L398), the previous implementation utilized:
```go
cleanRP := filepath.Clean(rp)
if strings.Contains(commandLine, cleanRP) { ... }
```
Because `/home/romeo/work/meta-repo` is an exact substring prefix of `/home/romeo/work/meta-repo-02`, any command executed in slot `02` falsely matched slot `01`.

The remediation introduces:
- Candidate pre-cleaning and stable sorting by descending cleaned path length (`len(candidates[i].clean) > len(candidates[j].clean)`). Longer worktree paths are evaluated prior to shorter prefix paths.
- `commandLineContainsRepoPath`: Scans for candidate paths and validates boundaries with `isCommandPathStartBoundary` (`' '`, `'\t'`, `'='`, `'"'`, `'\''`, `':'`, `';'`, `','`) and `isCommandPathEndBoundary` (`'/'`, `'\\'`, `' '`, `'\t'`, `'"'`, `'\''`, `':'`, `';'`, `','`).
- If a command line contains `/home/romeo/work/meta-repo-02`, the character following `meta-repo` is `'-'`, which is explicitly rejected by `isCommandPathEndBoundary`. Thus, prefix leakage is structurally impossible even if evaluated in isolation.
- Unit test coverage in [internal/supervisor/execution_detector_test.go:TestMatchCommandLineRepoPath_PreventsPrefixCollisionAcrossMultiSlotRepos](file:///Users/romeo/work/meta-repo-02/iazio-agent/internal/supervisor/execution_detector_test.go#L150-L173) validates both direct paths and subpath flag variants (`-C /home/romeo/work/meta-repo-02/vigo-api`).

### 2.2 Worktree Lease Ack Handshake Propagation (`iazio-agent`)
In [internal/worker/dispatcher.go](file:///Users/romeo/work/meta-repo-02/iazio-agent/internal/worker/dispatcher.go#L1335-L1345), `ackLeaseWithWorktree` is encapsulated as a context-aware closure:
```go
ackLeaseWithWorktree := func(ackCtx context.Context, activeConvID string) error {
    if wtAcker, ok := d.client.(interface {
        AckLeaseWithWorktree(ctx context.Context, jobID, leaseToken string, agentPID int, activeConvID, worktreePath string) error
    }); ok {
        return wtAcker.AckLeaseWithWorktree(ackCtx, job.ID, job.LeaseToken, os.Getpid(), activeConvID, worktreeDir)
    }
    return d.client.AckLease(ackCtx, job.ID, job.LeaseToken, os.Getpid(), activeConvID)
}
```
All three lease acknowledgment sites:
1. Immediate Phase 2 post-reservation lease ack ([L1345](file:///Users/romeo/work/meta-repo-02/iazio-agent/internal/worker/dispatcher.go#L1345)),
2. Heartbeat failure recovery retry loop ([L1373](file:///Users/romeo/work/meta-repo-02/iazio-agent/internal/worker/dispatcher.go#L1373)),
3. Story discovery conversation re-ack ([L1468](file:///Users/romeo/work/meta-repo-02/iazio-agent/internal/worker/dispatcher.go#L1468)),
now invoke `ackLeaseWithWorktree`, ensuring the control plane always receives the explicit `worktreeDir`.

### 2.3 Exclusive Worktree Binding & Sibling Lock Eviction (`iazio-harness-api`)
In [internal/control/engine.go](file:///Users/romeo/work/meta-repo-02/iazio-harness-api/internal/control/engine.go#L2167-L2221):
- `findExplicitHostRepoSlot` detects whether `cleanWT` targets an explicit repository slot by exact cleaned path comparison or numbered slot alias.
- When `explicitSlot != nil`, `BindDispatchJobRepo` binds directly to `explicitSlot` without falling through to generic slot-family heuristics.
- Sibling lock eviction: It iterates over `e.repos` and evicts any other repo holding `cleanJobID` (`r.Lock = LockIdle`, `r.RunningJobID = ""`, `r.LockHolder = ""`, notifying listeners via `e.notifyRepoLocked(r)`).
- Stale dirty pause reconciliation: If `explicitSlot.Queue == QueuePaused` with `ReasonDirty`, `ReasonAdhocASE`, or `ReasonDetached`, it resets `Queue = QueueOpen` and `Reason = ""`.
- Heartbeat lock consistency ([internal/control/catalog.go:HeartbeatWithCapabilities](file:///Users/romeo/work/meta-repo-02/iazio-harness-api/internal/control/catalog.go#L350-L407)) applies the identical sibling eviction and pause clearing logic when processing runner heartbeats.
- External dispatch active checks ([internal/control/engine.go:isExternalDispatchJobActiveLocked](file:///Users/romeo/work/meta-repo-02/iazio-harness-api/internal/control/engine.go#L1023-L1038)) return `false` if `aj.WorktreePath` targets another repo on the host.

### 2.4 HTTP Dispatch Projection & Queue Metadata Synchronization (`iazio-harness-api`)
- In [internal/dispatch/queue.go:UpdateRuntimeMetadata](file:///Users/romeo/work/meta-repo-02/iazio-harness-api/internal/dispatch/queue.go#L3783-L3793), both `job.Repo` and `job.WorktreePath` are kept in sync when a runner reports its worktree path.
